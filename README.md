# SOAR-RL-Agent

Projet de base pour un agent d’apprentissage par renforcement (RL) orienté SOAR.

## Structure

- backend/: API, services, environnement, RL, entraînement et métriques
- frontend/: interface web pour visualiser l’état du système
- datasets/: jeux de données d’entraînement
- saved_models/: modèles sauvegardés
- training_results/: résultats d’expériences
- docker/: configuration Docker
- docs/: documentation
- .github/: workflows CI/CD

## Démarrage rapide

```bash
docker compose up --build
```
